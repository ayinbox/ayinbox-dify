# Security policy

Report a vulnerability in this plugin, or in AY Inbox, by email to team@ayinbox.com. Do not open a public issue or pull request for it.

Include what you found, how to reproduce it and which version of the plugin you used (the `version` in `manifest.yaml`). We answer every report and tell you when a fix ships.

Never send a real API key in a report. If a key was exposed, revoke it in the AY Inbox dashboard and create a new one.
